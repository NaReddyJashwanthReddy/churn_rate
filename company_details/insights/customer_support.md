Support tickets strongly correlate with churn (leading indicator)
Churn happens 1–3 weeks after first complaint
Premium users are more sensitive to issues
Billing failures are high-risk churn triggers
No structured sentiment or feedback scoring exists
Resolution impact is not tracked (big opportunity gap)
Key Insight (this is senior-level thinking)

Support data is not just “complaints”.

It is:

A pre-churn behavioral signal system

This means later in modeling, we can create features like:

number of tickets in last 7/30 days
time since last complaint
complaint category frequency
sentiment proxy score
unresolved ticket count
